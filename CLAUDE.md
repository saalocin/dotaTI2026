# Dota 2 — The International 2026 Prediction Workspace

## Vision

This workspace exists to build well-researched, data-driven picks for the Dota 2 TI 2026 in-client
event, with the goal of maximizing total event points across all three point-earning tracks:

1. **Group Stage Predictions** — place all 16 teams into Swiss-outcome buckets
   (16 predictions, up to 12,000 pts; locks Aug 13 02:00 UTC).
2. **The International Predictions** — fill out the 8-team double-elim bracket series-by-series
   (14 predictions, up to 12,000 pts; picked after groups complete).
3. **Fantasy** — draft 5 players from 3 teams (support duo / safelane+offlane duo / mid),
   optimize War Banners (emblems, quality, traits) and coach titles each period; scored by
   percentile vs. all other players (up to 12,000 pts per period).

## Rules Reference

The official rules — transcribed from the in-client screenshots in `assests/` — live in
[TI2026_Rules.md](TI2026_Rules.md). That file is the **source of truth** for all scoring math and
constraints (plus researched tournament facts and data caveats); consult it before any prediction,
scoring, or optimization work, and update it when new rule details or screenshots appear.

## Architecture (Medallion)

- **Bronze** (`data/bronze/<source>/<snapshot>/…`) — raw API payloads exactly as fetched, immutable,
  with `manifest.jsonl` per snapshot. Bronze is the system of record.
- **Silver** (`data/silver/ti2026.duckdb`) — normalized, fully rebuilt from bronze on every
  `ti build-silver` (silver is disposable). Schemas: `pred` (teams domain: series, games,
  ratings, standings, bracket, odds), `fan` (players domain: 18-stat `player_game_stats`,
  scoring views `fantasy_points` / `player_series_points`), `meta` (calendar, calibration, lineage).
- **Gold** (`gold` schema in the same DuckDB; `src/ti2026/gold/`) — decision marts, fully
  rebuilt by `ti build-gold` (must run after `build-silver`, which deletes the DB file):
  `team_strength` + 16×16 `matchup_probs` (recency-weighted Bradley-Terry on roster-majority
  games, wayback-Glicko + `seeds/manual_priors.csv` priors, rho series-shock), Monte Carlo
  draw tables (`sim_group_draws`/`sim_bracket_draws`/`sim_fantasy_paths` — Swiss win-4/lose-4
  with structural counts asserted, elim round, double-elim per `seeds/bracket_topology.csv`),
  slate optimizers writing `gold.slates` + `data/gold/decisions/*.json`. Point tables are
  convex ⇒ slates are optimized against joint draws, never per-pick marginals.
- **Seeds** (`seeds/*.csv`, git-tracked, hand-verified) — 16-team crosswalk (Liquipedia ↔ OpenDota
  ids + aliases), 80-player roster with positions, 14-slot bracket topology, event calendar,
  coach titles (`coach_titles.csv`, transcribed from client), fantasy hero tags
  (`hero_tags.csv`, generated by `ti ingest dotaclient` from the local client's
  npc_heroes.txt "Adjectives" — refresh after client patches, then rebuild silver+gold),
  REAL Swiss buckets (`swiss_buckets.csv`, captured from the client compendium definition
  league 19719 — 4-0/4-1/elim-victor/elim-loser/1-4/0-4), war-banner slot layouts
  (`banner_layouts.csv`, TI2025 precedent until confirmed by banner screenshots).
  **Never join teams by raw name** — always via the crosswalk (renames: BoomBoys=ex-BetBoom,
  Iron Wing=ex-1w/Tundra, HULIGANI=ex-L1GA TEAM, TEAM VISION=ex-PARIVISION — Liquipedia
  renders BOTH names for the latter on the same TI pages).

### Data sources (ranked; see plan research)

| Source | Role | Notes |
|---|---|---|
| OpenDota | Fantasy primary: 16/18 stats exact + team form | keyless (free tier suffices, per OpenDota support); explorer SQL for bulk |
| Liquipedia api.php | Predictions primary: pages + Glicko-2 ratings | 1 req/2s, parse 1/30s, UA w/ contact, **CC-BY-SA 3.0 attribution required** |
| STRATZ GraphQL | **Series ground truth** (seriesId + best-of per match → `pred.match_series`) + gap-filler | needs `STRATZ_TOKEN` + literal `User-Agent: STRATZ_API`; 25-alias batched queries |
| Polymarket | **Market benchmark**: live "TI 2026 Winner" market (+ per-series markets during events) → `pred.market_odds` | keyless gamma API; intraday snapshots preserve drift |
| Steam news | Patch/TI announcement timeline → `meta.news` | keyless ISteamNews (appid 570) |
| Dota client VPK | Hero fantasy tags (title prefixes) → `seeds/hero_tags.csv` | local install, `ti ingest dotaclient`; re-run after patches |
| datdota | Cross-check | **currently blocked** (Cloudflare TLS-level 403) — deferred |
| Odds | Fallback series odds | manual entry in `seeds/manual_odds.csv`; egamersworld snapshot fetcher |

Probed and parked: bo3.gg (open JSON API — overlaps STRATZ best-of + Polymarket odds),
Wayback copies of datdota (CDX flaky, low marginal value).

Liquipedia data is CC-BY-SA 3.0 — anything published from this workspace must attribute Liquipedia.

**Key parsing fact:** Liquipedia match wikitext is empty `{{Match}}` placeholders even for finished
events — series data only exists in the **rendered HTML** (`action=parse&prop=text`). Parsers in
`src/ti2026/parse/liquipedia_html.py` handle brackets (slot mapping via DOM nesting depth),
swiss matchlists, standings; game-level Valve match ids come from the popup stratz/datdota links.

## Commands

```bash
uv run ti status                 # bronze snapshots + silver row counts
uv run ti ingest liquipedia      # TI pages + rankings (slow: 30s/parse call)
uv run ti ingest opendota --bootstrap --teams --explorer-backfill
uv run ti ingest wayback         # archived Portal:Rankings (time-correct priors)
uv run ti ingest players         # Liquipedia bios + Steam avatars + team logos
uv run ti ingest polymarket      # TI-winner market snapshot (intraday, keyless)
uv run ti ingest steamnews       # official Dota 2 news feed
uv run ti ingest stratz --series-backfill   # real seriesId + best-of per match
uv run ti ingest dotaclient      # hero fantasy tags from the local Dota client VPK
uv run ti build-silver           # full rebuild of ti2026.duckdb (drops gold too!)
uv run ti build-gold             # ratings + matchup matrix + 50k tournament sims
uv run ti backtest [--tune]      # walk-forward model validation vs baselines
uv run ti sim --stage post_groups [--entrants ...]   # fixed-entrant bracket draws
uv run ti pick group|bracket|fantasy                 # optimized slates + JSON export
uv run ti verify                 # end-to-end sanity checks (silver + gold + post-groups state)
uv run ti live                   # daily live sequence (ingest→silver→gold→verify)
uv run pytest -q                 # parser + scoring + sim + optimizer tests
```

Daily during TI (Aug 13–23): run `uv run ti live` ~1h after the last series (OpenDota parse lag
20–60 min), then `ti dashboard` + republish the artifact. **`ti live` is stage-aware**: once
the 4 UB QF slots are seeded in `pred.bracket_slots` it automatically appends the post-groups
tail — fixed-entrant `sim --stage post_groups` (20k fantasy paths) → `optimize_bracket` →
`optimize_rosters` (P2, 5-emblem banners, 8 alive teams) with decision JSON exports — so the
bracket slate and Fantasy·P2 board survive every gold rebuild. Post-groups the dashboard also
scores every group-slate variant against `slates.actual_buckets` and ships the interactive
Bracket Lab (packed 2,000-draw joint sample). First 2 days of each stage: calibrate
madstone/stuns/TFP vs the in-client scoreboard into `meta.stat_calibration` (screenshot
scoreboards into `assests/`).

## Layout

- `assests/` — in-client rule screenshots (folder name spelling is intentional)
- `TI2026_Rules.md` — rules source of truth
- `seeds/` — hand-verified ground truth CSVs (incl. `manual_priors.csv`, `swiss_buckets.csv`
  — fill the real bucket rules there when the client reveals them on Aug 13)
- `src/ti2026/` — pipeline: `bronze/` (fetch), `parse/` (payload→records), `silver/` (DDL+builders), `gold/` (models/sims/optimizers), `cli.py`, `verify.py`
- `tests/` — pinned-fixture regression tests (real TI2026-qualifier match, completed TI2025 pages)
- `data/` — gitignored bronze/silver
- `.env` — `CONTACT_EMAIL` (Liquipedia UA), `OPENDOTA_API_KEY` (optional), `STRATZ_TOKEN` (set)
